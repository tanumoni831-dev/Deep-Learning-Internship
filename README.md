# Deep Learning - Sentiment Analysis

## About
IMDB Movie Review Sentiment Analysis
using LSTM - InternSpark AI Internship Task 2

## Environment Setup
- Platform: Google Colab
- Language: Python 3
- Framework: TensorFlow 2.20.0

## Libraries Used
- tensorflow, keras
- numpy, matplotlib

## Dataset
- IMDB Movie Reviews (built-in)
- 25000 training, 25000 testing samples

## Model Architecture
- Embedding Layer
- LSTM Layer (64 units)
- Dropout Layers
- Dense Output Layer

## How to Run
1. Open notebook in Google Colab
2. Run all cells in order
3. Model auto trains on IMDB dataset

## Results
| Metric | Score |
|---|---|
| Train Accuracy | 98.55% |
| Test Accuracy | 84.48% |

## Conclusion
LSTM model successfully classifies
movie reviews as positive or negative!
